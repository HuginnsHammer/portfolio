Selected projects

LLMShield — AI application security gateway

  • Added policy decisions, a mock provider, SQLite audit metadata, optional API-key checks, and a React dashboard.
  • Added a synthetic evaluation harness that reports precision, recall, false-positive rate, and false-negative rate separately for prompt-injection, PII, and secret detection, with regression tests.
  • CI runs tests, linting, type checks, and the frontend build; evaluation results are documented as diagnostic synthetic metrics, not real-world benchmarks.

CloudSentry — Static configuration scanner

  • Implemented 10 documented rule IDs covering selected Terraform, Dockerfile, and Docker Compose misconfigurations.
  • Improved source-line attribution for Terraform resources and Compose services so findings point closer to the relevant configuration.
  • Hardened reasoned suppressions: narrow line scope, warnings for ineffective directives, and retained suppressed findings in JSON/API audit output.
  • Made CLI scans exit with an error code when any input file cannot be scanned, preventing partial scans from appearing clean; added regression tests for these behaviors.
